**后续主方案：** [bead-fs-v2-algorithm.md](./bead-fs-v2-algorithm.md)（基于 FS 优化）  

**实现文件：** `index/js/bead-handlike.js`（独立模块，**不**并入 `image-utils.js`）

## 1. 目标与非目标

### 目标（趋近手绘）

- 区域平整、色块可读，**不用** Floyd–Steinberg / Bayer 全图抖动  
- 色数可控（预算 `maxColors`），色差以「块内一致」优先于「像素级逼真」  
- 保留可拼性：轮廓不断、五官/嘴唇等高对比结构不被抹成一团  
- 可复用：Web / 小程序只调同一纯函数 API

### 非目标

- 不追求照片级渐变还原  
- 不替代人工修图（画笔 / 桶填仍是终态）  
- 不与旧 `FGImage.quantizeImageData` 混写逻辑

### 与主流算法的差异（摘要）

| | 主流（FS 等） | 本方案 |
|--|--------------|--------|
| 单位 | 像素 + 误差扩散 | **区域 / 结构** 为主 |
| 中间色 | 邻格杂色「骗」眼睛 | 有限中间色阶 + 边界 1 格软边 |
| 失败态 | 噪点、色数膨胀 | 海报化过硬、小结构并块（持续治理） |

## 2. 管线（现行）

输入：已缩放到棋盘尺寸的 `ImageData`（一格一豆）+ 品牌/自定义色板。

```text
① 估计全图肤色 ab 锚点（皮肤采样中位 a*/b*）
② Lab 中位切割聚类（略多于 maxColors，偏好劈开 L → 光影带）
③ Diversity snap：簇 → 色板（肤色簇在锚点色相族内按 L 选）
④ 建结构掩码：protect + detail（肤区忽略温和光影梯度，避免当「细节」乱跳色相）
⑤ 赋色：
     - 唇 / 发 → 源 Lab 直接最近珠
     - 全部肤色（含轻度细节）→ 色相锁定后的 L 分档（ΔL≠Δ色相）
     - 其它细节 / 非肤 → 簇或直映
⑥ 硬边界软化：肤↔肤只插同色相族中间明度；发↔肤、唇不插
⑦ 色数预算：超量并色；极亮/极暗珠不因「用量少」被砍
⑧ 去孤岛：触 protect 保留；与邻域众数 ΔE 过大拒合并
⑨ 填 1 格洞（跳过 protect）
```

### 公开 API

| 方法 | 用途 |
|------|------|
| `quantizeImageData(imageData, paletteColors, opts)` | Web：返回量化后 ImageData |
| `imageToGrid(imageData, paletteColors, opts)` | 复用：`grid[y][x] = paletteId \| -1` |
| `version()` | 如 `0.3.0-handlike` |

### 主要 opts

| 键 | 默认 | 含义 |
|----|------|------|
| `maxColors` | 32 | 用色预算上限 |
| `minRegion` | 3 | 去噪最小连通面积 |
| `skinBias` | 0.7 | 肤色匹配强度 |
| `diversity` | 0.85 | 簇 snap 时惩罚已用珠 |
| `edgeSoftDelta` | 18 | 触发软边的邻色 ΔE |
| `mergeMaxDelta` | 14 | 去噪允许合并的最大 ΔE |
| `protectExtrema` | true | 是否建结构保护/细节掩码 |
| `skinHueLock` | 0.72 | 肤色 ab 拉向全图锚点的强度（0–1） |
| `skinHueSlack` | 11 | 优选肤色珠相对锚点的 ab 半径 |
| `cleanPasses` | 2 | 去噪遍数 |
| `alphaCut` | 16 | 透明阈值 |

色板色对象需含 `rgb: [r,g,b]`，可选 `id`。

## 3. 已知失败模式 → 对策（对照用）

改图验收时按此表看，避免「针对单张图 hardcode」。

| 现象 | 常见原因 | 对策方向 |
|------|----------|----------|
| 全图噪点、色数爆炸 | 开了 FS/Bayer | 用手绘风模式；勿把抖动加回主路径 |
| 脸左右两刀切、缺中间调 | 簇过粗 / 无 L 分档 | 肤色 L 分档 + 肤↔肤软边 |
| **左右脸色相分裂**（原图只是光影） | 阴影侧落到另一色相族；细节掩码把 ΔL 当特征 | **肤色锚点 + hue lock**；肤区不因温和梯度走自由近邻 |
| 阴影脏橙 | 近邻落到高 b\* 珠 | 肤色 ab 约束 + 惩罚 muddy warm + 锚点族内选珠 |
| 色板 52 只用一半 | 多簇 snap 到同一珠 | diversity snap + 略超聚簇 |
| 高光/瞳孔没了 | 去噪吞极值岛 | protect 掩码 |
| **嘴成一色块** | 唇被当肤色 L 分档 / 并岛 | 唇检测 + detail 直映 + ΔE 拒并 |
| **耳/发际粗糙或糊** | 小结构被簇抹平或发肤乱插中间色 | hair/detail 直映；禁止发↔肤软边 |
| 背景碎块 | minRegion 过小 | 调高 minRegion / cleanPasses（平坦区） |

## 5. Changelog（增量）

格式：版本 · 日期 · 改了什么 · 针对哪类失败 · 验收注意。

### 0.1.0 · 2026-10-22

- **新增**独立模块与 Web 试点选项/预设。  
- 管线：Lab 聚类 → 最近珠 → 色预算 → 形态去噪/填洞；**无抖动**。  
- 针对：主流抖动噪点、色过多。

### 0.2.0 · 2026-10-22

- Diversity snap；肤色 L 分档；惩罚脏暖橙。  
- 硬边界 1 格中间色；L 极值/强边 protect。  
- 预算不砍极亮/极暗稀有珠。  
- 针对：脸硬切、色板利用率低、阴影脏橙、高光被抹。  
- 验收：同图同 52 色，对比左右脸过渡与眼部高光。

### 0.3.0 · 2026-10-22

- **细节层**：`detail` / 唇色（高 a\*）/ 发色（低 L）像素 **源 Lab 直接映珠**，不走簇+肤色分档。  
- 结构掩码同时产出 `protect` + `detail`（梯度、Laplacian、色度离群、唇、发际）。  
- 软边跳过 发↔肤、唇。  
- 去噪：邻域众数与本色 ΔE > `mergeMaxDelta` 则**拒绝合并**（防嘴并进肤色）。  
- `minRegion` 默认 3；去噪尺度略放宽。  
- 针对：嘴成一色、耳/发细节粗糙。  
- 验收：唇线是否分上下/口缝；耳廓是否可辨；发际是否仍乱插中间色。

### 0.4.0 · 2026-10-22

- **肤色色相锚点**：全图皮肤采样中位 a\*/b\*；赋色时 ab 拉向锚点，再在色相族内按 L 选珠（`skinHueLock` / `skinHueSlack`）。  
- 全部肤色像素（含轻度细节）走 hue-locked 路径；唇/发仍自由直映。  
- 结构掩码：肤区提高「细节/强边」阈值，避免把柔和光影梯度当成特征去自由近邻。  
- 肤↔肤软边只插同色相族中间明度。  
- 针对：**左右脸色相差被夸大**（原图多为 ΔL，算法误成粉 vs 褐/橄榄）。  
- 验收：同光比人像下，左右脸应同色相深浅阶，而非两套无关肤色；阴影仍可读但不脏跳色相。

### 2026-10-22 · 主路径否决

- 产品结论：Handlike 整体效果不佳，**否定为自研主方案**。  
- `bead-handlike.js` **保留不删**；新主线见 `docs/bead-fs-v2-algorithm.md`。  
- 本文不再要求继续升版本迭代，除非显式做考古/对照实验。
