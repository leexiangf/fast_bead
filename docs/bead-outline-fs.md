---

## 1. 产品目标

贴纸风卡通图 → 拼豆网格：

1. 取出主体  
2. **外轮廓**钉成近黑珠（向外描，不吃掉主体边缘色）  
3. 轮廓外清透明（预览仍画空珠位网格）  
4. 轮廓内 Floyd–Steinberg  

适用：扁平贴纸 / 卡通。人像仍用经典 FS。

---

## 2. v1 稳定管线（冻结时约定）

```
边框估纸色 → 色度距纸色 + Otsu → 最大连通域（+近邻卫星）
→ 圆滑(闭运算+浅去尖) → expandNearPaint → fillHoles
→ 外向描边 → FS → rim 清理(depth=2) → 清真正外部
```

要点：

- **纸色** = 图边不透明像素均值  
- **v1 主体分** = opponent-chroma 距纸色（高饱和色块友好，灰白易翻车 → 见 V2）  
- **描边向外**：黑珠落在 exterior 邻接格，不替换主体最外圈  
- **清外部**：仅从边框洪水可达的 `!subject`；内部洞（眼睛）先 `fillHoles`  
- **rim**：描边内侧 2 格把椒盐吸到邻色；卫星块可 `rimProtect` 跳过

## 3. 问题 → 原因 → 解法（按时间）

### 3.1 描边失败 / 像没变

| 现象 | 原因 | 解法 |
|------|------|------|
| 调了像没效果 | 未声明变量抛错，UI 仍显示上一张 FS | 独立模块 + try/catch；勿静默吞错 |
| 描边看不见 | 「最深珠」实为暗红 | `nearestColor(0,0,0)` 钉黑 |
| 黑环被吃掉 | 量化后多数表决平滑 | outline 路径**禁止** `smoothMajority` |

### 3.2 主体分割

| 现象 | 原因 | 解法 |
|------|------|------|
| 沙地/画布进主体 | RGB 距离 / 绝对色度把米色当图 | 边框纸色 + **opponent-chroma**（v1） |
| 只有眼睛有「描边」 | 用暗像素当核 | 禁止暗核种子；外轮廓来自主体边界 |
| 一只眼透明 | 低饱和眼被当纸洞；`clearExterior` 清掉所有 `!subject` | `fillHoles`；只清边框可达外部 |
| 灰白猫只剩粉耳/爱心 | 色度≈纸，Otsu 只留高饱和碎片 | **V2**：Lab 距纸 + **从边框洪水填「像纸」**，填不到的为整图 |
| 浅色奶油：描边只剩头、FS 稀糙 | 奶黄≈纸 + 细线缝漏 | 曾试 2.0.3 灌进 v2 伤螃蟹 → 回滚；现 **独立模型** `outline-fs-pale`：墨线封缝 + 绝对 Lab 纸门 + 本模型内 FS 拉开 |

### 3.3 轮廓外与预览

| 现象 | 原因 | 解法 |
|------|------|------|
| 要去背景 | 轮廓外仍是沙色珠 | `clearExterior`：非外部洞透明 |
| 「没有网格了」 | 透明格被 `drawBeadGrid` 跳过 | 透明格画淡空珠位（`image-utils`） |

### 3.4 黑框偏紧 / 边缘杂色

| 现象 | 原因 | 解法 |
|------|------|------|
| 腿/爪比原图瘦（如 10→8） | **内向**描边吃掉主体最外圈 | **外向**描边；略放宽 Otsu；`expandNearPaint` |
| 扩边后黑边内抖动杂色 | 扩进的过渡带 + FS 椒盐 | `cleanRimColors` depth=2（「完美」螃蟹关键） |

### 3.5 色数与 UI

| 现象 | 需求 | 解法 |
|------|------|------|
| 只要部分色 | 与手绘风一样限色 | 各抖动传 `maxColors`；`limitPaletteToBudget` |
| 散色合并难找 | 放预览样式下 | `params-pair--sparse` 挪到 view/ncolors 下 |

### 3.6 角 / 尖刺丢失（恐龙）

| 现象 | 原因 | 解法 |
|------|------|------|
| 头/尾黄角没了 | 原稿黑描边低饱和=「纸」→ 角与身断开；`largestCc` 丢掉卫星 | `keepMainAndSatellites`（缝宽内合并） |
| 并回后又没了 | `smooth`/`expand` 末尾又 `largestCc` | 收尾用卫星合并，**禁止**只留最大块 |
| 角在但变绿/变没 | rim 把整根细角吸成邻色 | 卫星像素 `rimProtect`；**不要**全局削弱 rim（会毁螃蟹） |
| 整圈吸黑加粗 | 暗色并进整圈轮廓 | 只在「主块↔卫星」廊道吸黑墨 |
| 恐龙角仍易丢、不想拧冻结版 | v1 缝宽偏紧 | **独立模型** `outline-fs-accent`：gap=7、minSize=1、expand=2、更长暗廊 |
| 已抠透明 PNG 仍估纸色翻车 | 白棋盘外是透明，纸色洪水不适用 | **独立模型** `outline-fs-alpha`：`alphaHard` 主体；软边再贴回；几乎无透明则色度回退 |
| 黑/深蓝底上的亮色角色 | 浅色纸假设翻车；灰白 v2 的 thr−14 会吃掉暗部 | **独立模型** `outline-fs-dark`：暗纸洪水 + 更紧纸门 + 多候选择优 |
| 深色底丢毛发/胡须，黑描边看不见 | Otsu OR 把门放宽吃中调；黑描边≈黑底 | **dark 1.0.1**：仅绝对暗门 + 亮/彩强制主体；深底改浅色描边珠 |
| 霓虹/光晕图像整幅 FS、抠不干净 | 柔光晕被当主体，黑底清不掉 | **独立模型** `outline-fs-neon`：高亮/高彩芯；晕+黑底可灌走；惩罚近满幅 mask |

### 3.7 改圆滑时的螃蟹回归（重要）

用户认定的「完美」≈：**外描边 + clearExterior + rim depth=2 + 腿根凹槽仍在**。

| 错误改动 | 回归 | 正确做法 |
|----------|------|----------|
| rim depth↓ 或「同色邻居≥2 不吸」 | 黑边内杂色回来 | 保持 depth=2；角只用 `rimProtect` |
| 只填缺口、取消去尖 + 强行还原 | 左脚多肉；右腿根无描边 | 凹槽须保持 exterior，外描边才能画关节 |
| `keepInterior` 双次闭运算 | 脚变肥、轮廓胖 | 内部白/眼靠 `fillHoles`；勿重闭运算撑外形 |
| 为修脚尖大改圆滑 | 整体不如「完美」 | **回退到完美基线再开 V2** |

### 3.8 版本策略

| 现象 | 解法 |
|------|------|
| 修 A 毁 B | v1 冻结；复制 `bead-outline-fs-v2.js` 试验 |
| 灰白图 v1 仍碎 | 用 **V2**（洪水），不要硬拧 v1 色度门 |
| 浅色旁路伤螃蟹色泽 | **回滚旁路**；再做浅色须排除纸底像素，且禁止默认 FS 拉开 |

## 4. 禁止回归（改代码前核对）

1. **不要**在 outline 路径后跑多数表决平滑。  
2. **不要**内向描边吃主体外圈。  
3. **不要** `clearExterior` 清内部洞；只清边框洪水外部。  
4. **不要**为护角全局关掉/削弱 rim；用 `rimProtect`。  
5. **不要**填深腿根凹槽（关节需要 exterior 才能描边）。  
6. **不要**对整圈主体吸暗色；廊道仅限主块↔卫星。  
7. **不要**在卫星合并后再 `largestCc` 只留一块。  
8. **不要**在 v1 上为灰白角色改色度门；改 V2。  
9. 预览透明外仍要有空珠网格。  
10. **不要**用含纸底的全局均值当「浅色」；**不要**对饱和图默认做 FS 相对纸色拉开（会毁螃蟹色泽）。

## 5. 验证清单

改 V2 / 若动 v1 时至少目视：

- [ ] **螃蟹**：外轮廓完整、腿根有描边、无明显多肉脚、黑边内无大片杂色  
- [ ] **恐龙**：头/尾黄角仍在，描边不过厚  
- [ ] **灰白猫**：全身+双耳，不是单耳/爱心碎片  
- [ ] 轮廓外透明 + 空珠网格  
- [ ] 色数预算仍生效  

自动化烟测（Node + `ImageData` polyfill）：灰身体+粉耳、黄角隔黑缝、橙主体+边缘杂色。

## 7. 后续改动建议

1. 描边五模型已齐；新场景继续**独立入口**，勿拧标准冻结版。  
2. 每修一类图，在本文 §3 加一行「现象 / 原因 / 解法」。  
3. UI 用场景名；`outline-fs` 保持冻结基线。  
4. 大改前用螃蟹「完美」对照图 + 灰白猫 + 带角恐龙各跑一遍。
